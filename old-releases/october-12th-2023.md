# October 12th, 2023

## Bug Fixes

* Fixed an issue with TradeStation symbols that impacted the ability to fetch quotes for symbols ending in the character `P`, `C` or `D`. For example the symbol `AMD` was affected by this issue.
* Fixed an issue with inviting a user to an account a 2nd time. If the user is invited, and then access is removed, the account was not able to be invited again.
