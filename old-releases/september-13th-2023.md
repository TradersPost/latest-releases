# September 13th, 2023

## Tradier

We removed beta flag from the [**Tradier**](https://traderspost.io/broker/tradier) integration. It has been in use for several months now by customers and we believe it is stable.

## Interactive Brokers (beta)

We made the [**Interactive Brokers**](https://traderspost.io/broker/ibkr) integration available for all TradersPost customers. Please remember that this integration is in <mark style="color:orange;">**BETA**</mark> and you may experience issues that we have not discovered yet. It is recommended to test with a paper account first. Read more about this integration in the [Interactive Brokers Documentation](https://docs.traderspost.io/docs/brokers/interactive-brokers). If you have any issues or questions, please email us at [support@traderspost.io](mailto:support@traderspost.io)

## Coinbase (beta)

We made the [**Coinbase**](https://traderspost.io/broker/coinbase) integration available for all TradersPost customers. Please remember that this integration is in <mark style="color:orange;">**BETA**</mark> and you may experience issues that we have not discovered yet. It is recommended to test with small position size first. Read more about this integration in the  [Coinbase Documentation](https://docs.traderspost.io/docs/brokers/coinbase). If you have any issues or questions, please email us at [support@traderspost.io](mailto:support@traderspost.io)
