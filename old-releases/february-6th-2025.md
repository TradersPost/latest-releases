# February 6th, 2025

## Enhanced User Experience for Strategy Access

We've improved the `Strategies > Access` section to enhance user management. Users can now manage access in bulk, allowing the addition or removal of multiple people simultaneously, making the process more efficient.

**New Features:**

* **Bulk Management**: Streamline your workflow by managing several users at once, reducing the need for individual adjustments.
* **Subscriber Insights**: Gain visibility into subscriber details, including whether their strategy subscription is active and specifying if it's in live or paper mode.

## Improve Subscribe to Strategy UI

Enhanced the subscription user interface to display only brokers supporting the strategy's asset class. Updated the confirmation modal to provide a preview, confirming the selected broker.

## Improve Broker Select Dropdown

We made a minor update to the connected broker selection dropdown in the strategy subscription settings. Now, it only displays brokers that support the strategy's asset class and clearly separates them into paper and live categories.

## Set Max Strategy Subscriptions Limit

We've set a system-wide cap of 200 subscriptions per strategy. If you reach this limit and need to add more subscribers, please contact us at [support@traderspost.io](mailto:support@traderspost.io).
